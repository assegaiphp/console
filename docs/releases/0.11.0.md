# Assegai Console 0.11.0

Console 0.11.0 changed the baseline for new projects and project updates to Core 0.11.

The release shipped an incomplete dependency transition: its recommendations kept several framework modules on 0.10. This violates the coordinated framework release policy. The upgrade instructions previously included here have been withdrawn pending a coordinated correction, package verification and Website upgrade guidance. This release's dependency recommendations must not be used as evidence that a complete 0.11 framework upgrade is available.

## New project baseline

`assegai new` now creates projects requiring `assegaiphp/core:^0.11.0`. The bundled Composer template and the shared project-default loader use the same requirement.

PHP 8.4+ remains required. Console's own dependency requirements are unchanged.

## Dependency transition defect

Core and Console moved to the 0.11 release line while the CLI recommended ORM, Events, Auth, Collections, Forms, Util and Validation on 0.10 and Common on `^0.10.1`. Those recommendations were a release coordination error.

`assegai add` and `assegai update` share the affected recommendations. Other first-party package names remain accepted. The correction must account for every first-party module and the established Attributes and queue-adapter version streams, including their compatibility with the framework release line.

Existing newer or custom project constraints must be reviewed without silently downgrading them or broadening their allowed versions.

Default recommendations no longer depend on Composer version metadata for the running CLI. CLI version reporting and self-update checks still identify the executing Console installation.

## Update behavior shipped in 0.11.0

The dry run lists requirement changes without modifying files or dependencies. Cross-release changes require confirmation; non-interactive updates require an explicit `--yes` after reviewing the plan. These safeguards do not validate the coordinated availability of every framework module.

Console 0.11 manages the Core 0.11 line and no longer accepts `--to=0.10`. Keep a Console release supporting Core 0.10 for maintenance of projects that must remain on that line. The update command does not downgrade projects.

If the project also requires Console, its requirement is updated alongside Core in the same Composer operation. Direct companion requirements under `require` and `require-dev` use the affected package recommendations described above.

The update preserves its existing safety boundaries: application PHP source is not rewritten, manifests are restored if Composer fails, and `vendor/` may require `composer install` after a failed dependency operation. Commit or back up the project before upgrading and run the application's tests afterward.
