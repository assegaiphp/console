# Assegai Console 0.10.2

Assegai Console 0.10.2 corrects the Events package policy for the coordinated AssegaiPHP 0.10 release.

## Events release-line alignment

Console 0.10.0 and 0.10.1 incorrectly recommended `assegaiphp/events:^0.9.0`. Events 0.10.0 is part of the framework-wide 0.10 release, so Console now derives its recommended Events constraint from the active framework line, just like Core and ORM.

As a result:

- `assegai add events` requires `assegaiphp/events:^0.10.0`
- `assegai update --to=0.10` aligns an existing direct Events 0.9 requirement to `^0.10.0`
- an Events release-line change participates in the update plan and cross-release approval gate
- already-newer Events constraints are preserved rather than downgraded

Queue drivers remain on their independently published 1.x compatibility lines; this correction does not change their constraints.

## Upgrade

Update the global CLI, preview the application dependency migration, and then approve it:

```bash
assegai global update
assegai update --to=0.10 --dry-run
assegai update --to=0.10
```

Automation must pass `--yes` after reviewing the dry-run plan. Console restores application manifests if Composer resolution fails.

## Validation

Regression coverage verifies that the Events recommendation matches the active framework line and that project updates replace direct Events 0.9 constraints with the coordinated 0.10 constraint.
